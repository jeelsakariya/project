✺ About Movie Explorer Portal

The Movie Explorer Portal is an education static web development project crafted specifically for B.Sc(HOUNERS) 1st Year Web Desining & Web & Web Technologies Lab & curriculum.

The Core goal of this Assignment is to teach students how to take a structured HTML document containing real-world movie metadata and apply progressive styling layers using standard CSS, frameworks like Bootstrap 5 or Tailwind CSS.

✺ Syllabus Progression Roadmap

  1. UNIT 1 - HTML:UNIT - 1 HTML5 Markup: Structuring semantic web documents, metadata,lists,tables and form inputs.
  2. UNIT 2 - CSS:CSS Fundamentals: Applying external stylesheet,selectors, color rules and uderstanding the Box Model. (Margin, Padding, Border)
  3. UNIT 3 - Responsive Design: CSS3 & Responsive Design: Creating fluid layouts using flaxbox, CSS grid,hovever transition and media query breakpoints.
  4. UNIT 4 - Bootstrap:Responsive Frameworks: Refactoring custom CSS layout into framework container grids using Bootstrap 5/Taiwind CSS.
